# 网页资产计 · Chrome 扩展

本目录可作为未打包的 Chrome 扩展直接加载，无需构建。

1. 打开 `chrome://extensions`，启用 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择本 `extension` 目录。
3. 更新源码后，在扩展卡片点击 **重新加载**，关闭旧的设置、商店页面再重新打开。

沿用原目录与浏览器配置即可继续使用本地数据；不要通过卸载旧扩展进行更新。

使用工具栏弹窗查看账本，点击 **进入增长商店** 打开独立页面，或在设置页开启 **自动补结算**。
所有金额均为虚拟资产，数据只保存在本机。

安装、完整装备表、解锁门槛、每周任务、演示与开发说明见 [项目 README](../README.md)。
