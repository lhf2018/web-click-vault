# 网页资产计 · Chrome 扩展

本目录是**可直接加载的未打包扩展**（无需构建）。

## 如何安装到 Chrome

1. 打开 `chrome://extensions`
2. 打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本文件夹：`G:\code\Page_Journey\extension`
5. 若已加载过，点扩展卡片上的 **重新加载**

首次安装会请求访问网页，用于注入停留计时探针（只统计可见时长，不读正文）。

## v0.2 新增

- **精准停留**：content script 按页面可见性累计
- **周视图**：Popup / 设置页近 7 日入账
- **会话防丢**：异常关闭后 Popup 可补结算或丢弃
- **SPA 策略**：默认忽略 History 路由；设置里可开启
- **公式可观测**：设置页展示最近一笔四项得分与噪声

## 使用方式

1. 浏览 `http/https` 网页
2. 关闭标签、跳转离开，或点「结算当前页」入账
3. Popup 查看今日入账、周曲线、恢复提示
4. 设置页调整 SPA / 查看公式拆解
