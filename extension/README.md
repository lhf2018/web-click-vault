# 网页轻度经营 · Chrome 扩展

本目录可作为未打包的 Chrome 扩展直接加载，无需构建。

1. 打开 `chrome://extensions`，启用 **开发者模式**。
2. 点击 **加载已解压的扩展程序**，选择本 `extension` 目录。
3. 更新源码后，在扩展卡片点击 **重新加载**，关闭旧的扩展页面和弹窗再重新打开。

沿用原目录与浏览器配置即可继续使用本地数据；不要通过卸载旧扩展进行更新。

工具栏弹窗展示今日入账、资产构成、近七日入账和近期流水。首页资产卡片仅保留 **查看资产汇总** 按钮，不展示累计资产、商店倍率或其他功能按钮。进入完整页面后，可从统一侧栏切换以下平级页面：

- **资产汇总**：查看现金、公司估值、地产估值、装备资产、藏品、投资市值与总资产估值。
- **增长商店**：购买和升级装备，查看收益预览及购买记录。
- **我的地产**：收购网站地契、经营和升级建筑。
- **我的公司**：创办多家公司，自动接单、交付、收款和升级；支持招聘、建设及稳健／精品／风险策略。
- **资产置换**：装备、地产、公司设施折价出售或置换。
- **项目投资**：20 个常驻项目（含 4 个大型项目）加 4 个当期项目，每三周上新 4 个。按份数买入，支持加仓、平均成本、部分卖出与全部卖出，最多同时持有 10 个项目。模拟数据每小时驱动行情，展示七日走势和盈亏，卖出扣 1% 手续费；过期项目仍可卖出，与任务无关。
- **收藏品**：集中查看独立行情、单件浮动价格与收购委托；浏览后自动发现与网页标题、主题色和代码元素有关的藏品，持有计入资产，可出售换取现金。
- **成就**：“探索越多，选择越多”合并 54 个里程碑与 9 项装备解锁，共 63 项进度，统一计数、分类和状态筛选。
- **账本与设置**：查看收入与浏览记录，调整计数、收益拆解和自动补结算，执行重置。
- **每周探索任务**：查看任务进度并领取本周奖励。

完整页面沿用统一侧栏。成就页仅保留一个成长区域，装备归入“装备解锁”分类；每周任务独立展示，商店不展示装备收藏总数或升级总等级。

当前为 **0.9.0 / schema 6**，文档更新于 **2026-11-18**。旧数据增量迁移，保留资产、装备、地产、公司与任务；迁移前保存原账本快照。投资和成就字段以默认值兼容。

藏品在资产汇总按发现时价值记账，收藏品页显示当前市价；出售按行情结算，无固定原价保底，原值以内转现金，只有溢价计入累计收益。投资按剩余份额的当前市值计入资产，卖出净到账含本金和盈亏，单独记录以避免重复计收入。旧投资零碎份额保留，可全部卖出清空。

成就解锁永久保留，不奖励额外现金；阅读、活跃日与不同网站从本次更新开始累计，其余按已有记录计算。重置今日保留持仓、成本、委托额度和成就；重置全部清空本地记录。

所有金额均为虚拟资产，数据只保存在本机。
