# 网页资产计 · web-click-vault

把有效网页浏览变成一笔笔本地虚拟资产，再用积累购买装备、经营地产、创办公司，并通过成就和每周任务查看成长进度。

**当前版本：0.7.0** · Chrome Manifest V3 · 无需构建 · 数据保存在本机

> 所有金额都是娱乐用途的虚拟资产，不涉及充值、提现或真实投资。装备不会产生离线利息，浏览收益来自有效网页访问与结算。

## 功能概览

- **资产汇总**：独立总览现金、公司估值、地产估值与装备资产；估值仅展示，不增加余额。公司按实际创办投入分摊成本，每升一级增加 25%；地产按当前等级累计购建成本、装备按历史投入计值。
- **装备解锁成就**：独立页面仅展示“探索越多，选择越多”的装备解锁路线、已解锁数量与各项门槛进度，沿用原有装备解锁规则。
- **浏览入账**：根据可见停留、加载速度、新鲜度和页面类型计算基础收益，关闭标签、导航离开或达到停留上限后结算。
- **本地账本**：查看今日收益、累计收益、浏览页数、近 7 日曲线和最近流水。
- **独立增长商店**：9 件永久装备、3 个分类，支持收藏筛选、价格及常驻加成性价比排序、场景收益预览。
- **互联网地产**：收购已浏览网站的虚拟地契，通过有效访问经营，从小摊位升级到总部。
- **多家公司自动经营**：创办出版社与探索事务所，自动接单、交付、收款和升级，查看各自的项目履历。
- **分阶段解锁**：累计收益和有效浏览页数同时达标才解锁；已拥有装备不会因新门槛重新上锁。
- **装备特效**：重访路径、探索域名、新路径和不同阅读时长可触发额外加成。
- **每周探索任务**：独立页面展示探索不同域名、深度阅读、跨日期探索的任务进度，完成后领取虚拟奖励。
- **会话恢复**：异常关闭留下的会话可手动补结算，也可开启自动补结算。
- **可调设置**：SPA 路由计数、公式拆解、自动补结算，以及本地数据重置。

## 安装与更新

### 首次安装

1. 克隆仓库或下载源码并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择仓库内的 **`extension` 子目录**，不是仓库根目录。
5. 从浏览器工具栏打开「网页资产计」，可将其固定到工具栏。

```bash
git clone https://github.com/lhf2018/web-click-vault.git
cd web-click-vault
```

扩展无需安装依赖、编译或启动服务器。安装时会申请网页访问权限，用于导航监听和可见停留计时。

### 更新已安装版本

1. 更新原来加载的源码目录；使用 Git 时可在仓库目录执行 `git pull --ff-only`。
2. 在 `chrome://extensions` 找到「网页资产计」，点击 **重新加载**。
3. 关闭旧的扩展页面和弹窗，再重新打开。已打开的普通网页建议刷新，让停留探针重新连接。

**沿用原扩展目录与同一浏览器配置，不要先卸载扩展。** 扩展 ID 或浏览器配置变化后，本地数据不会自动搬迁。项目目前没有数据导入、导出或云同步功能。

旧版账本自动迁移至 schema 6，保留已有资产、历史、设置、成就、装备等级、每周任务和地产。迁移前在本地保存一份原账本快照（`assetMeterBackupBeforeSchema6`），不会在后续读取时覆盖，已有 schema 5 快照也保留；不修改已有会话。旧购买不会补造购买历史，任务和公司订单不会回推旧浏览记录。地产发现列表可从已有近期浏览流水初始化，经营进度不回推。

## 开始使用

1. 正常浏览 `http://` 或 `https://` 网页，停留时间按页面可见状态累计。
2. 关闭标签、导航离开，或达到 180 秒停留上限时结算。
3. 点击扩展图标查看今日入账，在 **资产汇总** 卡片查看现金、公司估值、地产估值与装备资产；弹窗不展示累计资产和商店倍率。
4. 点击 **查看资产汇总** 进入完整页面，通过侧栏的 **增长商店** 购买升级；在 **成就** 页查看装备解锁路线，在 **每周探索任务** 独立页查看进度和领取奖励。
5. 点击弹窗右上角设置图标，调整计数及补结算策略。

同一规范化 URL 在约 90 秒内去重。快速反复刷新通常不会重复入账，也不会增加每周任务进度。浏览器内部页和扩展页不计入浏览收益。

## 资产与收益规则

### 余额和累计收益

```text
可用余额 = 累计收益 − 商店累计消费 − 地产累计消费 − 公司累计消费
```

- **累计收益**包含浏览入账、已领取任务奖励、地产经营收入与公司订单报酬，购买和升级不会扣减累计收益。
- **今日入账和周曲线**记录收入，不减去购物支出。
- **可用余额**用于购买装备、收购和升级地产、创办公司；解锁门槛看累计收益，花钱不会使进度倒退。
- **累计浏览页数**只增加有效浏览结算次数，任务奖励、地产收入与公司报酬不增加页数。
- 最近浏览及奖励流水最多保留 50 笔，日汇总保留 14 天，商店展示最近 30 次购买。

### 资产汇总估值

```text
总资产估值 = 可用现金 + 公司估值 + 地产估值 + 装备资产
```

- **公司估值**：将实际公司累计投入按创办顺序的权重 `1、2、3……N` 分摊，再乘以 `1 + 25% × (公司等级 − 1)`；最高为创办成本的 2 倍。
- **地产估值**：按持有地产当前等级的累计购建成本计算，包括地契与已完成等级的升级费用。
- **装备资产**：按历史装备累计消费计算；旧版未记录的消费不会按当前等级反推补造。
- 估值只用于展示，不计入现金，不提供出售或变现。公司与地产经营收入已进入现金，不重复加入估值；总部挂牌不重复计算地产。

### 入账公式

```text
Score = 0.45 × 停留得分 + 0.20 × 加载得分 + 0.20 × 新鲜度得分 + 0.15 × 页面类型得分
Noise ~ Uniform(-0.08, +0.08)
基础入账 = round(clamp(10 × Score × (1 + Noise), 0.30, 10), 2)

常驻倍率 = 1 + Σ(装备等级 × 每级常驻加成)
实际倍率 = 常驻倍率 + Σ(本笔满足条件的装备等级 × 每级额外特效)
浏览入账 = round(基础入账 × 实际倍率, 2)
```

基础单次入账上限为 ¥10，装备加成后的最终入账可以超过 ¥10。所有加成相加，不相互连乘。

例如，笔记本和工作台各 1 级时，常驻倍率为 `1 + 0.10 + 0.30 = 1.40`；本笔可见停留达到 15 秒，再触发工作台的 `+0.20`，实际倍率为 `1.60`，基础 ¥5 最终入账 ¥8。

普通结算与补结算均采用**结算时**的装备等级，加成不追溯已经入账的收益。设置页可查看最近一笔浏览的基础金额、实际倍率及触发特效。

## 互联网地产

从弹窗点击 **查看资产汇总**，再通过侧栏进入 **我的地产**。页面沿用增长商店样式，与装备共用可用余额。

- 每块虚拟地契售价 **¥500**，最多持有 **3 块**；当前不支持出售或扩展地产位。
- 有效浏览结算后发现网站，保留最近 100 个。按主机名划分，仅合并 `www.` 前缀，其他子域名分别经营，不读取网页正文。
- 持有地契后，可见停留 **≥15 秒**的有效结算获得经营收入，每块每天最多 **3 次**，继续遵守 URL 去重。补结算按实际结算日期计入。

- 经营收入作为独立流水计入余额、今日收益、周曲线与累计收益，不叠加装备倍率，不增加浏览页数或每周任务进度。
- 升级同时要求资产、累计经营次数和不同经营日期，无连续签到要求。重置今日保留地产、支出、进度及当日经营额度；重置全部清空地产和迁移快照。

## 多家公司自动经营

从任一完整页面的侧栏进入 **我的公司**。输入名称、选择主营业务与地址，支付创办费用后立即自动接单；可以持有多家公司，也可以创办多家同类公司，名称不可重复。

- 首家创办费用 **¥1,000**，第 N 家为 **¥1,000 × N**。公司消费单独记账，与装备、地产共享余额；公司日常经营不自动扣款。
- **出版社**：首级订单需要 3 个不同页面的可见阅读，每次至少 60 秒，报酬 ¥80。页面按来源与路径区分，查询参数和片段不重复推进。
- **探索事务所**：首级订单需要 5 个不同域名的有效浏览，每次至少 15 秒，报酬 ¥100；仅归一化 `www.` 前缀。
- 每家公司独立处理当前订单。同一次有效浏览可同时推进多家公司，但每家公司最多推进一步；完成后自动交付、收款并接下一单，不将本次浏览转入下一单。
- 每完成 5 单自动升一级，最高 5 级。等级 L 的订单目标为首级目标 + L − 1，报酬为首级报酬 × L；每家公司保留最近 30 项作品履历。
- 没有订单期限、维护费或离线收入；不读取网页正文。仅接入后续有效浏览结算，遵守现有 URL 去重，补结算按实际结算时间推进。
- 公司报酬单独入账，不叠加装备倍率，不增加浏览次数，不推进每周任务、地产或其他公司订单。
- 可选已持有地产作为总部地址，仅用于展示，不改变地产收益。当前不支持注销、改名或切换主营业务。
- 重置今日保留公司、投入、订单进度和履历；重置全部会清空公司及迁移快照。

## 每周探索任务

任务以**浏览器本地时间的周一**为一周起点，在下一次读取账本或结算时刷新。进度从支持任务的版本开始记录，不回推历史；补结算计入实际结算所在周和日期。

| 任务 | 完成条件 | 奖励 |
| --- | --- | ---: |
| 探索新视野 | 本周浏览 5 个不同域名，每个可见停留至少 15 秒 | ¥100 |
| 沉浸阅读者 | 本周完成 5 次可见停留至少 60 秒的有效浏览 | ¥150 |
| 保持好奇心 | 本周在 3 个不同日期各完成一次至少 15 秒的有效浏览 | ¥200 |

- 从完整页面侧栏进入 **每周探索任务** 独立页面，点击 **领取奖励**，每个任务每周只能领取一次。原有任务进度和领奖记录保留。
- **必须在本周领取**；下周刷新时，旧进度和未领取奖励清空。
- 奖励计入余额、今日入账、累计收益和收入流水，可推动累计收益成就与装备解锁。
- 奖励不享受装备加成、不增加浏览次数，也不会推进任务本身。
- 单次有效浏览可以同时推进多个任务；域名任务按主机名去重，并将 `www.` 前缀归一化。

## 设置与会话恢复

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 计入 SPA / History 路由 | 关闭 | 开启后，同文档的路径切换也参与结算和新会话记录 |
| 显示公式拆解 | 开启 | 在设置页展示最近一笔浏览的得分、噪声、倍率和特效 |
| 自动补结算 | 关闭 | 自动处理异常关闭或扩展重启留下的待结算会话 |

开启自动补结算时，会立即处理当前待补结算记录；之后启动及定期扫描发现的异常会话也会自动处理。关闭时，弹窗保留 **补结算 / 丢弃** 选择。补结算继续遵守 URL 去重规则。

**重置今日**保留累计收益、装备、地产、公司、各类消费、经营进度和每周任务进度；**重置全部数据**会清空本地账本、装备、地产、公司、任务、会话和迁移快照，无法撤销。

## 本地演示与开发

### 交互演示

## 隐私与权限

扩展通过 `chrome.storage.local` 保存资产、装备、地产、公司及订单履历、任务进度、近期 URL / 域名、会话信息和迁移快照。不读取网页正文，不向服务器上传浏览记录；数据不跨设备同步。

| 权限 | 用途 |
| --- | --- |
| `storage` | 保存本地账本、设置与会话 |
| `tabs`、`windows` | 跟踪标签、窗口与当前会话状态 |
| `webNavigation` | 感知页面导航与可选的 SPA 路由切换 |
| `alarms` | 定期结算、日期检查与异常会话扫描 |
| `http://*/*`、`https://*/*` | 注入可见停留计时探针 |

## 常见问题

**更新后看不到商店或新设置？** 仅刷新设置页不足以更新后台。请先在 `chrome://extensions` 重新加载扩展，再关闭旧页面并重新打开。

**自动补结算勾选后又取消，或显示后台版本过旧？** 按上面的步骤重新加载扩展与设置页；正常保存后会显示“设置已保存”。

**点击创办公司没有反应？** 查看创办按钮下方的提示，确认名称已填写、余额充足。如果提示公司后台未更新，到 `chrome://extensions` 重新加载扩展，再关闭并重新打开公司页，不要卸载。若提示后台响应超时，先重新打开页面确认是否已创办，再重试。

**有余额为什么还买不了？** 余额、解锁条件与满级限制分别校验。查看商品提示，确认累计收益和浏览页数均达标。

**为什么没有立刻涨钱或增加任务进度？** 账本和任务在有效结算后更新，后台标签不持续增加可见停留。快速重复访问还可能被 90 秒去重规则过滤。

**为什么倍率与商品卡预览不同？** 概况显示常驻倍率；场景预览还会加上满足条件的特效。最终金额取决于本笔基础得分、噪声和结算时装备等级。

## 未来规划

以下为待探索的玩法方向，均尚未实现，具体规则、优先级与上线时间待后续确定。所有玩法使用娱乐用途的虚拟资产，不涉及真实资金交易。

互联网地产基础玩法已实现，见上方“互联网地产”；后续可探索地产位扩展与专业化经营路线。

多家公司自动经营基础玩法已实现，见上方“多家公司自动经营”；公司设施、研究业务、客户关系、招聘与收购留待后续探索。

### 虚拟资产拍卖行

- 每天出现随机藏品，例如绝版域名地契、古董服务器和神秘数据箱。
- 支持直接购买或参与模拟竞拍，让积累的资产有新的消费目标。
- 藏品具有不同品相、稀有度和套装效果，形成长期收藏玩法。

### 一周一次的投资远征

- 投入资产购买补给、组建远征队，并选择稳妥或冒险路线。
- 在接下来几天，通过深度阅读和域名探索帮助队伍推进。
- 远征结束后带回虚拟资产、稀有装备或意外战报，形成每周投入与收获的期待。

### 会涨跌的虚拟市场

- 引入带宽、算力、数据水晶等虚拟商品，通过每日供需事件影响价格。
- 可以低价买入、择机卖出，也可以消耗材料升级装备。
- 事件提前提供线索，让交易包含观察与判断。

### 用资产改造自己的私人空间

- 从一间小办公室开始，使用资产购买书架、鱼缸、街景窗和服务器机房等设施。
- 将装备摆放到空间中，支持布置与点击互动。
- 让长期资产积累转化为可见、可定制的私人空间。
