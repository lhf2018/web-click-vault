# web-click-vault

把每次有效网页浏览折算成一笔本地「资产」入账的 Chrome 扩展。  
数据只保存在本机，不做正文分析，不上传浏览历史。

## 功能概览

- **动态入账**：按停留、加载、新鲜度、页面类型加权，基础单次 ≤ ¥10，商店加成另计
- **增长商店**：用虚拟余额购买永久升级，提升后续浏览收益
- **自动结算**：关闭标签或跳转离开后入账
- **周视图**：近 7 日入账曲线
- **会话防丢**：异常关闭后可在 Popup 补结算
- **SPA 策略**：默认忽略 History 路由（设置里可开）
- **公式可观测**：设置页可查看最近一笔得分拆解

## 安装（加载已解压的扩展）

1. 打开 Chrome：`chrome://extensions`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择本仓库里的 `extension` 目录：

```text
web-click-vault/extension
```

5. 首次加载会请求访问网页权限（用于停留计时探针）

修改代码后，在扩展管理页点击 **重新加载**。

## 使用

1. 正常浏览 `http/https` 网页
2. 关闭标签或跳到其他网站后自动入账
3. 点击工具栏图标查看今日入账、至今访问页数、周曲线与最近一笔
4. 在设置页调整 SPA 计数、查看公式拆解或重置数据

## 入账公式

```text
deposit = clamp(round(10 × Score × (1 + Noise), 2), 0.30, 10)

Score = 0.45·停留 + 0.20·加载 + 0.20·新鲜度 + 0.15·页面类型
Noise ~ Uniform(-0.08, +0.08)
```

同一 URL 在约 90 秒内去重，避免短时重复打开虚增。

## 隐私

- 使用 `chrome.storage.local`，默认不离开浏览器
- 只统计有效 http(s) 打开；排除浏览器内部页与扩展页
- 停留按页面可见性累计，后台标签不计时
- 不读取页面正文，不上传流水

## 增长商店

弹窗点击「进入增长商店」打开独立页面，可购买 9 件永久装备，每件最多 10 级。原有三件装备保持原来的价格和加成：

| 商品 | 首级价格 | 每级收益加成 | 下一级价格增长 |
| --- | --- | --- | --- |
| 灵感笔记本 | ¥50 | +10% | ×1.65 |
| 效率工作台 | ¥250 | +30% | ×1.8 |
| 增长引擎 | ¥1,000 | +100% | ×2 |

加成相加：各买一级后，之后结算的浏览收益为基础入账 ×2.4。
价格按基础价格 × 增长系数的当前等级次方计算，四舍五入到分。
可用余额 = 累计入账 − 商店累计消费；今日入账、历史曲线和成就仍按累计收益统计。
已有数据自动兼容，原累计资产全部可用。普通结算和补结算均按结算时的升级等级计入加成。
升级不追溯已入账收益；重置今日保留升级，重置全部数据清空升级和消费。
所有金额均为本地虚拟资产。

验证：`node --test extension/tests/shop.test.mjs`

## 自动补结算

在扩展设置页开启「自动补结算」，当前待补结算记录会立即入账；之后启动扩展及定期扫描时发现的异常会话也会自动处理。
关闭后恢复 Popup 中的手动补结算或丢弃提示。旧数据默认关闭此选项，其余设置与资产保持不变。

### 探索成长（0.5.0）

商品按累计收益与累计有效浏览页数分阶段解锁，两项必须同时达标。所有已拥有装备可继续升级，不因新门槛被锁回。
原有常驻加成完整保留，额外增加行为特效。常驻倍率与特效倍率相加，商品卡可切换场景预览。

| 装备 | 收益 / 页数门槛（同时满足） | 每级额外特效 |
| --- | --- | --- |
| 灵感笔记本 | 初始开放 | 全场景常驻加成 |
| 星光书签 | ¥500 / 50页 | 当日重访路径 +15% |
| 效率工作台 | ¥3000 / 200页 | 可见停留至少15秒 +20% |
| 探索指南针 | ¥12000 / 500页 | 当日首次探索域名 +40% |
| 增长引擎 | ¥50000 / 1000页 | 全场景常驻加成 |
| 私人图书馆 | ¥150000 / 2000页 | 可见阅读至少60秒 +70% |
| 灵感观测站 | ¥500000 / 4000页 | 当日探索新路径 +200% |
| 复利反应堆 | ¥2000000 / 8000页 | 可见阅读至少120秒 +400% |
| 星际传送门 | ¥10000000 / 15000页 | 当日首次探索域名 +1000% |

每周任务（本地时间周一刷新）：

- 探索 5 个不同域名，每个可见停留至少15秒：奖励 ¥100。
- 完成 5 次可见阅读至少60秒的有效浏览：奖励 ¥150。
- 在 3 个不同日期各完成一次至少15秒的有效浏览：奖励 ¥200。

从本版本的有效结算开始记录，不回推历史。补结算按结算所在周计入。
奖励需在本周手动领取一次，过周未领取失效；奖励不享受装备加成、不增加浏览次数或任务进度。
领取会增加余额、今日入账和累计收益，记录任务奖励流水，成就继续按累计收益解锁。
进度仅在本机持久化，不同域名最多保留5个、日期最多3个，过周清空。
旧版迁移至 schema 4，不扣余额、不重置装备、历史和设置。
