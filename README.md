# 网页轻度经营 · web-click-vault

把有效网页浏览变成一笔笔本地虚拟资产，再用积累购买装备、经营地产、创办公司，并通过成就和每周任务查看成长进度。

**当前版本：0.9.0 / schema 6** · 文档更新：2026-11-18 · Chrome Manifest V3 · 无需构建 · 数据保存在本机

> 所有金额都是娱乐用途的虚拟资产，不涉及充值、提现或真实投资。装备不会产生离线利息，浏览收益来自有效网页访问与结算。

## 功能概览

- **被动网页收藏**：有效浏览低概率发现网站专属奇物，收藏品页集中展示单件浮动价格、走势和收购委托；资产汇总按发现时价值记账，出售按当周行情结算。
- **项目份额投资**：24 个在售项目，含 4 个大型项目；独立模拟行情每小时变化，支持自选份数、加仓、平均成本及部分卖出，每三周更换 4 个当期项目。
- **资产出售与置换**：装备、地产及公司设施按可核实投入的 70% 回收，可同类卖旧买新。
- **资产汇总**：总览现金、公司、地产、装备、藏品与投资市值。公司按实际创办投入分摊成本，每升一级增加 25%；地产按累计购建成本、装备按历史投入减已处置成本计值，投资随市价变化。
- **成就里程碑**：54 个永久成就，涵盖浏览、阅读、活跃、网站探索、财富、收藏、地产、公司、装备和投资，支持分类与状态筛选，保留装备解锁路线。
- **浏览入账**：根据可见停留、加载速度、新鲜度和页面类型计算基础收益，关闭标签、导航离开或达到停留上限后结算。
- **本地账本**：查看今日收益、累计收益、浏览页数、近 7 日曲线和最近流水。
- **独立增长商店**：9 件永久装备、3 个分类，支持收藏筛选、价格及常驻加成性价比排序、场景收益预览。
- **互联网地产**：收购已浏览网站的虚拟地契，通过有效访问经营，从小摊位升级到总部。
- **多家公司自动经营**：创办出版社与探索事务所，自动接单、交付、收款和升级，查看各自的项目履历。
- **分阶段解锁**：累计收益和有效浏览页数同时达标才解锁；已拥有装备不会因新门槛重新上锁。
- **装备特效**：重访路径、探索域名、新路径和不同阅读时长可触发额外加成。
- **每周探索任务**：独立页面展示探索不同域名、深度阅读、跨日期探索的任务进度，完成后领取虚拟奖励。
- **会话恢复**：异常关闭留下的会话可手动补结算，也可开启自动补结算。
- **可调设置**：SPA 路由计数、公式拆解、自动补结算，以及本地数据重置。

## 安装与更新

### 首次安装

1. 克隆仓库或下载源码并解压。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择仓库内的 **`extension` 子目录**，不是仓库根目录。
5. 从浏览器工具栏打开「网页轻度经营」，可将其固定到工具栏。

```bash
git clone https://github.com/lhf2018/web-click-vault.git
cd web-click-vault
```

扩展无需安装依赖、编译或启动服务器。安装时会申请网页访问权限，用于导航监听和可见停留计时。

### 更新已安装版本

1. 更新原来加载的源码目录；使用 Git 时可在仓库目录执行 `git pull --ff-only`。
2. 在 `chrome://extensions` 找到「网页轻度经营」，点击 **重新加载**。
3. 关闭旧的扩展页面和弹窗，再重新打开。已打开的普通网页建议刷新，让停留探针重新连接。

**沿用原扩展目录与同一浏览器配置，不要先卸载扩展。** 扩展 ID 或浏览器配置变化后，本地数据不会自动搬迁。可在「账本与设置 → 数据备份」导出或导入 JSON 备份；导入覆盖当前账本并清除进行中的会话，导入前的账本另存于本地备份。暂不支持云同步。

旧版账本自动迁移至 schema 6，保留已有资产、历史、设置、成就、装备等级、每周任务和地产。迁移前在本地保存一份原账本快照（`assetMeterBackupBeforeSchema6`），不会在后续读取时覆盖，已有 schema 5 快照也保留；不修改已有会话。旧购买不会补造购买历史，任务和公司订单不会回推旧浏览记录。地产发现列表可从已有近期浏览流水初始化，经营进度不回推。

## 开始使用

1. 正常浏览 `http://` 或 `https://` 网页，停留时间按页面可见状态累计。
2. 关闭标签、导航离开，或达到 180 秒停留上限时结算。
3. 点击扩展图标查看今日入账，在 **资产汇总** 卡片查看现金、公司估值、地产估值与装备资产；弹窗不展示累计资产和商店倍率。
4. 点击 **查看资产汇总** 进入完整页面，通过侧栏购买装备、经营公司、查看收藏品和交易项目份额；在 **成就** 页查看 54 个里程碑和装备路线，在 **每周探索任务** 页领取奖励。
5. 点击弹窗右上角设置图标，调整计数及补结算策略。

同一规范化 URL 在约 90 秒内去重。快速反复刷新通常不会重复入账，也不会增加每周任务进度。浏览器内部页和扩展页不计入浏览收益。

## 资产与收益规则

### 余额和累计收益

```text
可用余额 = 累计收益 + 藏品回收转入 + 资产出售所得 + 投资卖出净到账 − 投资买入支出 − 商店累计消费 − 地产累计消费 − 公司累计消费 − 公司招聘建设投入 − 公司经营亏损
```

- **累计收益**包含浏览入账、已领取任务奖励、地产经营收入、公司订单净收益、藏品出售溢价与旧版项目投资利润，购买和升级不会扣减累计收益。
- **今日入账和周曲线**记录收入，不减去购物支出。
- **投资卖出净到账**包含卖出份额的本金与盈亏，已扣 1% 手续费，使用 `investmentReturned` 单独累计；买入支出记入 `investmentSpent`。投资交易不再次增加累计收益，避免将返还本金重复记为收入；已实现盈亏在持仓和交易流水中展示。旧版项目返本记录仍兼容。
- **可用余额**用于购买装备、收购和升级地产、创办公司；解锁门槛看累计收益，花钱不会使进度倒退。
- **累计浏览页数**只增加有效浏览结算次数，任务奖励、地产收入与公司报酬不增加页数。
- 最近浏览及奖励流水最多保留 50 笔，日汇总保留 14 天，商店展示最近 30 次购买。

### 资产汇总估值

```text
总资产估值 = 可用现金 + 公司估值 + 地产估值 + 装备资产 + 持有藏品估值 + 投资市值
```

- **公司估值**：招聘和建设投入按原始支出计值；将实际公司累计创办投入按创办顺序的权重 `1、2、3……N` 分摊，再乘以 `1 + 25% × (公司等级 − 1)`；最高为创办成本的 2 倍。
- **地产估值**：按持有地产当前等级的累计购建成本计算，包括地契与已完成等级的升级费用。
- **装备资产**：按历史装备累计消费减已处置成本计算；旧版未记录的消费不会按当前等级反推补造。
- **藏品估值**：资产汇总和弹窗按发现时价值记账，收藏品页按当周行情展示市值；出售按行情结算，无固定原价保底。回收转入为成交价和原值中的较小者，超出原值的溢价计入累计收益，折价会减少账面总资产。
- **投资市值**：剩余份额 × 当前每份价格；持仓成本和浮动盈亏不单独再次加到总资产。卖出后相应份额移除，净到账进入现金。
- 装备、地产与公司设施可在资产置换页折价出售，公司主体及员工不出售。公司与地产经营收入已进入现金，不重复加入估值；总部挂牌不重复计算地产。

### 入账公式

```text
Score = 0.45 × 停留得分 + 0.20 × 加载得分 + 0.20 × 新鲜度得分 + 0.15 × 页面类型得分
Noise ~ Uniform(-0.08, +0.08)
基础入账 = round(clamp(10 × Score × (1 + Noise), 0.30, 10), 2)

常驻倍率 = 1 + Σ(装备等级 × 每级常驻加成)
实际倍率 = 常驻倍率 + Σ(本笔满足条件的装备等级 × 每级额外特效) + 本笔适用的成就加成
浏览入账 = round(基础入账 × 实际倍率, 2)
```

基础单次入账上限为 ¥10，装备加成后的最终入账可以超过 ¥10。所有加成相加，不相互连乘。

例如，笔记本和工作台各 1 级时，常驻倍率为 `1 + 0.10 + 0.30 = 1.40`；本笔可见停留达到 15 秒，再触发工作台的 `+0.20`，实际倍率为 `1.60`，基础 ¥5 最终入账 ¥8。

普通结算与补结算均采用**结算时**的装备等级，加成不追溯已经入账的收益。设置页可查看最近一笔浏览的基础金额、实际倍率及触发特效。

## 互联网地产

从弹窗点击 **查看资产汇总**，再通过侧栏进入 **我的地产**。页面沿用增长商店样式，与装备共用可用余额。

- 每块虚拟地契售价 **¥500**，最多持有 **3 块**；支持折价出售，暂不支持扩展地产位。
- 有效浏览结算后发现网站，保留最近 100 个。按主机名划分，仅合并 `www.` 前缀，其他子域名分别经营，不读取网页正文。
- 持有地契后，可见停留 **≥15 秒**的有效结算获得经营收入，每块每天最多 **3 次**，继续遵守 URL 去重。补结算按实际结算日期计入。
- **经营收入 = 本笔装备加成前的基础浏览收益（最高 ¥10）× 当前地产经营系数**，四舍五入到分；无离线收入。
- 经营收入作为独立流水计入余额、今日收益、周曲线与累计收益，不叠加装备倍率，不增加浏览页数或每周任务进度。
- 升级同时要求资产、累计经营次数和不同经营日期，无连续签到要求。重置今日保留地产、支出、进度及当日经营额度；重置全部清空地产和迁移快照。

## 多家公司自动经营

从任一完整页面的侧栏进入 **我的公司**。输入名称、选择主营业务与地址，支付创办费用后立即自动接单；可以持有多家公司，也可以创办多家同类公司，名称不可重复。

- 首家创办费用 **¥1,000**，第 N 家为 **¥1,000 × N**。公司消费单独记账，与装备、地产共享余额；招聘和设施主动购买时扣款，订单制作费及薪酬从合同报酬中结清；主动开启的风险订单可能扣除最多 ¥20 亏损。
- **出版社**：首级订单需要 3 个不同页面的可见阅读，每次至少 60 秒，报酬 ¥80。页面按来源与路径区分，查询参数和片段不重复推进。
- **探索事务所**：首级订单需要 5 个不同域名的有效浏览，每次至少 15 秒，报酬 ¥100；仅归一化 `www.` 前缀。
- 每家公司独立处理当前订单。同一次有效浏览可同时推进多家公司，但每家公司最多推进一步；完成后自动交付、收款并接下一单，不将本次浏览转入下一单。
- 每完成 5 单自动升一级，最高 5 级。等级 L 的订单目标为首级目标 + L − 1，报酬为首级报酬 × L；每家公司保留最近 30 项作品履历。
- 没有订单期限、维护费或离线收入；不读取网页正文。仅接入后续有效浏览结算，遵守现有 URL 去重，补结算按实际结算时间推进。
- 公司报酬单独入账，不叠加装备倍率，不增加浏览次数，不推进每周任务、地产或其他公司订单。
- 可选已持有地产作为总部地址，仅用于展示，不改变地产收益。当前不支持注销、改名或切换主营业务。
- 重置今日保留公司、投入、订单进度和履历；重置全部会清空公司及迁移快照。

### 公司建设与风险经营

公司共用个人余额，不设独立账户。旧公司、旧订单保持原有进度和报酬；所有人员、设施、策略变化从下一单生效。

- 每家公司一个员工位。编辑／研究员招聘 ¥200，合同报酬 +25%、目标 +1、每单薪酬 ¥12；业务助理招聘 ¥150，目标 −1（至少 2）、每单薪酬 ¥10。可免费解聘，当前订单薪酬仍按接单时约定结清。不按时间或离线扣工资。
- 资料架 ¥300，每单制作费减少 ¥5（最低为零）；专业工作台 ¥600，合同报酬 +20%。均为一次性建设，每家公司各一件。
- 稳健策略沿用基础订单；精品策略目标 +2、合同报酬 ×1.6、制作费 ¥15；风险策略合同报酬 ×1.5、制作费 ¥20。员工和工作台报酬加成相乘，薪酬与制作费在最后扣除。
- 风险策略需主动确认：每单 90% 正常交付，10% 返工净亏 ¥20，亏损已包含全部费用，不重复扣薪酬。连续亏损两单自动切回稳健。开启或自动接单时余额不足 ¥20 不接风险单；在途订单交付时余额不足，按基础合同报酬减已约定薪酬结算，并切回稳健。多家公司按创办顺序结算，逐单检查可用资金，不借债。
- 正常交付仅净收益进入今日收入、累计收入和周曲线。风险亏损单独记支出流水并减少现金，不倒扣累计收益、不推进任务。公司页展示累计净收益与最近交付结果。
- 招聘建设消费单独记账，并按投入计入公司估值，不改变原创办成本分摊。重置今日保留团队、设施、策略和亏损，重置全部清空。

## 被动网页收藏

从完整页面侧栏进入独立的 **收藏品** 页面。徽章、书签、芯片是外形模板，每个网站拥有自己的藏系，按归一化域名、页面路径与外形生成藏品身份、编号和纹样，不设固定种类清单。支持按网站、页面和藏品名搜索。站点公开名称取自 og:site_name（最多 50 字），无名称则用域名；不读取正文。旧藏品即时兼容展示，不改原有名称或价值。无需主动采集，有效浏览结算后自动发现藏品，不回推历史浏览。

- 可见停留至少 30 秒才有掉落机会，基础概率 3%（收藏成就可提高），首次也不保证获得。每天最多 3 件，同一网站每天最多 1 件，仅合并 `www.` 前缀。
- 每个来源页面只发现一次，页面按 origin + pathname 区分，忽略查询参数和片段。出售仍保留历史发现，不重新掉落。历史最多保留 600 件，达到上限暂停掉落。
- 网页含代码块时获得 **代码芯片（基础价 ¥30）**；否则停留至少 60 秒获得 **阅读书签（基础价 ¥20）**；其他情况获得 **网站徽章（基础价 ¥10）**。上述“稀有度”表示藏品类别，不是额外随机概率。
- 藏品使用网页标题，优先使用六位十六进制主题色，否则按域名生成配色。未收到网页元素时使用域名作为标题。不会加载外部图片。
- 探索等级 = 1 + floor(累计有效浏览页数 / 100)，最高 Lv.10，不受消费影响。新藏品价格随等级平滑增长：Lv.1 徽章/书签/芯片为 ¥10/¥20/¥30，Lv.5 为 ¥50/¥100/¥150，Lv.10 为 ¥180/¥360/¥540，再叠加随机整数品相修正 −15% 至 +15%，保留两位小数，最高 ¥621.00；结算新增页数后确定获得等级并锁价，后续升级不追溯改价，旧藏品保留原价。
- 发现时价值作为资产汇总和弹窗的账面估值保留；收藏品卡片展示当周市价及涨跌。按行情或委托报价出售，无原价保底：原值以内转入现金，溢价独立计收入，折价减少总资产。出售不增加浏览页数，也不推进任务或公司订单。
- 补结算遵守相同规则，按实际结算日期记掉落额度。重置今日保留藏品、出售所得及当日额度，重置全部清空收藏。
- 沿用 schema 6，以新增默认字段兼容已有账本，不变更旧资产。收藏品演示地址为 [本地收藏品演示](http://127.0.0.1:4173/collection/index.html)，可用顶部按钮模拟浏览。

## 藏品行情、资产置换与项目投资

藏品行情合并到收藏品页，资产置换与项目投资各有独立侧栏页面，共用现金，沿用 schema 6，以新增字段兼容旧账本。

- **藏品行情**：按浏览器本地周一轮换，每周本地模拟市场事件、品类指数和单件买家需求共同定价，单件行情限制在发现时估值的 65%～140%，与当前等级、成就无关。同周刷新不重新随机，提供近六周指数。每周指定一类藏品，按单件当周行情再加价 10% 收购，全账户限 2 件；收藏品卡片直接展示当前市价、相对发现时涨跌、六周价格走势与委托报价，取消固定原价保底回收。报价跨周失效，出售前需重新查看。出售时原值转现金，溢价作为独立收入，折价减少总资产；不会推进浏览、任务、地产、公司或投资。
- **资产置换**：装备按整件出售并清空等级，地产出售释放位置并将相关公司总部改为线上办公室，设施出售仅影响后续订单。按可核实投入 70% 回收；装备历史缺成本时按剩余历史总投入比例分摊，绝不按当前等级补造成本。历史支出保留，处置成本另记并从估值扣除。可同类卖旧买新，目标装备仍须解锁，地产仍须先发现；购买失败整笔回滚。地产当天经营额度跨出售与重购保留。员工及公司主体不出售。
- **项目池**：同时开放 24 个独立项目（20 个常驻 + 4 个当期项目），涵盖内容、社区服务、能源、物流、游戏、云计算、机器人等领域。以 2026-01-05 UTC 为起点，每 21 天自动更换 4 个当期项目，页面显示下次上新日期。每期 ID 独立，离线跨多期后按当前日期展示，不依赖任务或手动刷新；过期项目停止买入和加仓，已有持仓继续计价与卖出。
- **份额交易**：买入填写整数份数，提供 10、100、1,000 份及最大可买快捷按钮，实时展示预计支付。支持同一项目追加投资并更新加权平均成本，也可部分卖出或全部卖出。买入和部分卖出单次为 1 至 10 亿份整数，单个项目持仓上限 10 亿份；旧零碎份额可通过全部卖出清空。实际按成交时行情结算，后台独立校验余额、份数和剩余持仓。
- **大型项目**：洲际清洁能源网络、近地轨道物流港、新世代晶圆基地和深蓝海底计算枢纽，基准每份价格分别为 ¥1,000、¥5,000、¥10,000、¥50,000，随行情独立变化；原项目价格模型保持不变，财富增长后可通过增加份数扩大投入。
- 行情完全独立于浏览、用户等级和任务。需求、营收、成本指数与市场情绪由时间及项目种子生成，按小时报价，需求与营收提高估值，成本抑制估值，情绪影响溢价；页面展示驱动指标、24 小时涨跌和近七日价格。属于本地模拟数据，不接真实证券行情。离线后重新打开直接演算当时价格，同一小时刷新不会重新随机。
- 最多同时持有 10 个不同项目，达到上限仍可加仓已持有且开放的项目。不设完成目标、不自动返本或续投。持仓按当前行情计入总资产，卖出按成交时市价扣 1% 手续费，到账金额包含本金与盈亏；部分卖出按份额比例分摊成本，已实现盈亏单独累计记录，浮动盈亏不进入现金，交易所得不重复记作浏览奖励。最多保留 300 笔持仓记录，加仓与部分卖出合并到原持仓。
- 旧版未完成项目按原投入与开始时刻的行情折算份额；已完成和已退出记录保持原样。
- 重置今日保留委托额度、资产交易、持仓份额、成本与已实现盈亏；重置全部清空。本地演示入口为 /collection/index.html、/exchange/index.html、/investments/index.html；旧 /market/index.html 自动跳转收藏品。

## 每周探索任务

任务以**浏览器本地时间的周一**为一周起点，在下一次读取账本或结算时刷新。进度从支持任务的版本开始记录，不回推历史；补结算计入实际结算所在周和日期。

| 任务 | 完成条件 | 奖励 |
| --- | --- | ---: |
| 探索新视野 | 本周浏览 5 个不同域名，每个可见停留至少 15 秒 | ¥100 |
| 沉浸阅读者 | 本周完成 5 次可见停留至少 60 秒的有效浏览 | ¥150 |
| 保持好奇心 | 本周在 3 个不同日期各完成一次至少 15 秒的有效浏览 | ¥200 |

- 从完整页面侧栏进入 **每周探索任务** 独立页面，点击 **领取奖励**，每个任务每周只能领取一次。原有任务进度和领奖记录保留。
- **必须在本周领取**；下周刷新时，旧进度和未领取奖励清空。
- 奖励计入余额、今日入账、累计收益和收入流水，可推动累计收益成就与装备解锁。
- 奖励不享受装备加成、不增加浏览次数，也不会推进任务本身。
- 单次有效浏览可以同时推进多个任务；域名任务按主机名去重，并将 `www.` 前缀归一化。

## 设置与会话恢复

| 设置 | 默认值 | 行为 |
| --- | --- | --- |
| 计入 SPA / History 路由 | 关闭 | 开启后，同文档的路径切换也参与结算和新会话记录 |
| 显示公式拆解 | 开启 | 在设置页展示最近一笔浏览的得分、噪声、倍率和特效 |
| 自动补结算 | 关闭 | 自动处理异常关闭或扩展重启留下的待结算会话 |

## 常见问题

**更新后看不到商店或新设置？** 仅刷新设置页不足以更新后台。请先在 `chrome://extensions` 重新加载扩展，再关闭旧页面并重新打开。

**自动补结算勾选后又取消，或显示后台版本过旧？** 按上面的步骤重新加载扩展与设置页；正常保存后会显示“设置已保存”。

**点击创办公司没有反应？** 查看创办按钮下方的提示，确认名称已填写、余额充足。如果提示公司后台未更新，到 `chrome://extensions` 重新加载扩展，再关闭并重新打开公司页，不要卸载。若提示后台响应超时，先重新打开页面确认是否已创办，再重试。

**有余额为什么还买不了？** 余额、解锁条件与满级限制分别校验。查看商品提示，确认累计收益和浏览页数均达标。

**为什么没有立刻涨钱或增加任务进度？** 账本和任务在有效结算后更新，后台标签不持续增加可见停留。快速重复访问还可能被 90 秒去重规则过滤。

**为什么倍率与商品卡预览不同？** 概况显示常驻倍率；场景预览还会加上满足条件的特效。最终金额取决于本笔基础得分、噪声和结算时装备等级。

### 虚拟资产拍卖行

- 每天出现随机藏品，例如绝版域名地契、古董服务器和神秘数据箱。
- 支持直接购买或参与模拟竞拍，让积累的资产有新的消费目标。
- 藏品具有不同品相、稀有度和套装效果，形成长期收藏玩法。

### 一周一次的投资远征

- 投入资产购买补给、组建远征队，并选择稳妥或冒险路线。
- 在接下来几天，通过深度阅读和域名探索帮助队伍推进。
- 远征结束后带回虚拟资产、稀有装备或意外战报，形成每周投入与收获的期待。

### 虚拟材料市场（待探索）

藏品每周行情与项目每小时行情已实现。下述方向指额外的材料消费及生产系统。

- 引入带宽、算力、数据水晶等虚拟商品，通过每日供需事件影响价格。
- 可以低价买入、择机卖出，也可以消耗材料升级装备。
- 事件提前提供线索，让交易包含观察与判断。

### 用资产改造自己的私人空间

- 从一间小办公室开始，使用资产购买书架、鱼缸、街景窗和服务器机房等设施。
- 将装备摆放到空间中，支持布置与点击互动。
- 让长期资产积累转化为可见、可定制的私人空间。

## 现有页签的成长体验

- **我的地产**：按域名生成稳定的林间、海岸、书巷或星港风格，建筑楼层随当前等级变化；成长路线展示下一等级还需的经营次数、天数和费用。
- **我的公司**：当前订单配有故事委托方、业务专长与品牌阶段；作品档案使用现有真实交付记录，故事不改变交付条件或报酬。
- **收藏品**：私人展柜最多陈列 3 件当前持有藏品；支持撤下，选择保存在本地账本。站点套系图鉴分别展示当前持有与历史发现的徽章、书签、芯片，旧藏品同样计入。出售后自动从展柜隐藏，历史图鉴保留。
- **成就**：系列勋章显示永久解锁进度，默认展示最接近完成的三条路线，展开可看全部系列；点击揭晓下一枚的目标线索。
- **资产汇总**：资产版图合并到总资产估值区域，展示现金、地产、公司、装备、藏品与投资的构成比例。

这些展示由已有记录推导，不重算资产、价格或奖励；仅展柜选择增加可选字段 `displayCollectibles`，旧账本无需迁移。重新加载扩展后使用，不要卸载。故事与街区风格均为游戏展示，不代表网站真实业务或客户关系。
